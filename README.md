# 个人知识库管理系统（Personal Knowledge Base）

一个基于人工智能技术的个人知识管理与智能学习系统，支持多源知识采集、文档管理、智能检索、知识问答、错题管理和个性化复习。

用户可以将分散的学习资料集中存储，通过自然语言提问快速获取相关知识，并利用错题分析与智能复习建议辅助学习。

## 一、项目背景与现有方案分析

随着数字化学习和人工智能技术的发展，个人知识管理、AI 知识问答和在线学习平台逐渐成为知识获取与学习辅助的重要工具。然而，现有方案在知识管理、智能检索和个性化学习支持等方面仍存在一些值得改进的问题。

### 1. 知识管理与组织成本较高

传统笔记和知识管理工具通常提供较为丰富的文档编辑、分类和协作功能，但面对来源多样、数量不断增长的学习资料，用户仍需要投入较多精力进行整理、分类和维护。不同类型的知识资料之间缺乏有效关联，也增加了后续查找和利用的难度。

### 2. 知识检索与智能问答存在局限

传统关键词检索对用户输入的关键词具有一定依赖，当用户无法准确描述目标内容时，检索效果可能受到影响。通用大语言模型虽然能够提供自然语言问答能力，但其回答不一定充分结合用户的个人知识资料，并且仍存在事实错误和信息来源不够可靠等问题。

### 3. 个性化学习支持不足

部分在线学习平台主要围绕课程内容、学习进度和统一的教学安排展开，对不同学习者的知识基础、薄弱环节和学习进度考虑不够充分。个性化学习系统虽然能够利用学习数据提供差异化支持，但其效果仍受到数据质量、算法适用性和学习者特征识别能力等因素影响。

### 4. 错题管理与持续复习衔接不足

传统错题管理方式主要侧重于错题收集、分类和再次查看，对错题背后所反映的知识薄弱环节缺乏持续跟踪。错题记录、知识点分析和复习安排之间如果缺少有效衔接，就难以形成持续改进的学习闭环。

### 5. 学习数据分析与实际行动脱节

部分学习分析工具主要通过学习时长、任务完成量和测试成绩等指标展示学习情况，但统计结果并不一定能够直接转化为可执行的学习建议。如何从学习数据中识别薄弱知识点，并进一步形成有针对性的复习任务，是值得研究和改进的方向。

## 二、项目设计思路

针对上述问题，本项目设计并实现一套集个人知识管理、智能检索、AI 知识问答和学习辅助于一体的个人知识库管理系统。

系统以个人知识资料和学习记录为基础，结合自然语言处理、Embedding、混合检索及大语言模型等技术，实现多源知识采集、统一组织、智能检索和知识问答。

在此基础上，系统引入错题管理、知识点分析和个性化智能复习建议，将知识积累、问题记录、薄弱环节识别和复习安排联系起来，形成从知识管理到学习反馈的完整应用流程。

## 三、项目简介

在日常学习过程中，知识资料往往分散在不同文件和平台中，查找困难，复习效率较低。

本项目设计并实现了一套个人知识库管理系统，通过文档解析、知识切分、混合检索和大语言模型等技术，实现知识的集中管理与智能利用。

系统同时引入错题管理、学习数据分析和个性化复习建议，形成从知识积累到学习反馈的完整流程。

## 四、核心功能

### 1. 多源知识采集
- 支持 Markdown、PDF、Word、代码等文件上传。
- 支持网页 URL 内容采集。
- 支持图片、视频等资料的上传与管理。
- 自动解析文档并进行知识切分与入库。

### 2. 智能检索与问答
- 支持自然语言提问。
- 结合关键词检索与向量检索进行混合检索。
- 使用 Agent 对检索结果进行排序和组织。
- 基于知识库内容生成回答。
- 提供相关知识来源，辅助用户核查答案。

### 3. 知识管理
- 支持自定义资料夹及分类管理。
- 支持文档重命名、移动和删除。
- 支持文档元数据修改。
- 支持标签创建、删除、置顶及关联管理。
- 支持按标签筛选知识文档。

### 4. 多用户与知识共享
- 支持模拟多用户身份切换。
- 支持个人资料管理。
- 支持文档和资料夹公开共享。
- 支持浏览共享知识及收藏内容。
- 实现用户数据访问隔离。

### 5. 错题管理
- 支持错题添加、编辑和删除。
- 支持错题知识点及错误原因记录。
- 支持错题复习状态管理。
- 记录复习次数和最近复习时间。
- 支持将已掌握错题标记为已掌握。

### 6. 学习数据分析
- 统计学习情况和错题数据。
- 分析知识点掌握情况。
- 识别薄弱知识点。
- 提供学习数据可视化。

### 7. 个性化智能复习建议
- 根据错题复习状态安排复习优先级。
- 综合薄弱知识点和最近复习时间计算推荐评分。
- 展示复习任务及推荐理由。
- 支持从推荐任务直接进入复习流程。

## 五、技术架构

| 层次 | 技术 |
|---|---|
| 前端框架 | React 19 |

## 七、本地运行

### 1. 环境要求

- Python 3.11+
- Node.js 18+
- npm
- DeepSeek API Key
- DashScope API Key（使用在线 Embedding 服务时需要）

### 2. 配置后端

进入项目目录：

```cmd
cd backend
```

创建虚拟环境：

```cmd
python -m venv .venv
```

安装依赖：

```cmd
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

根据 `shared/config.py` 中的配置，在 `backend/.env` 中设置所需环境变量：

```env
DATABASE_URL=sqlite:///./pkb.db

LLM_API_KEY=你的DeepSeek_API_Key
LLM_BASE_URL=https://api.deepseek.com

EMBEDDING_API_KEY=你的DashScope_API_Key
EMBEDDING_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
EMBEDDING_MODEL=text-embedding-v3
```

启动后端：

```cmd
.venv\Scripts\python.exe -m uvicorn main:app --reload
```

后端默认运行地址：

- 服务地址：http://localhost:8000
- API 文档：http://localhost:8000/docs
- 健康检查：http://localhost:8000/health

### 3. 配置前端

新开一个 CMD 窗口，在项目根目录执行：

```cmd
cd frontend
```

安装依赖：

```cmd
npm install
```

启动前端：

```cmd
npm run dev
```

前端默认访问地址：

http://localhost:5173

## 十二、实际应用场景与解决的问题

### 1. 应用场景：大学生日常学习与考前复习

以大学生的日常学习为例，学习资料通常来自课程 PDF、Word 讲义、网页文章、代码示例和个人笔记等不同渠道。随着资料不断积累，用户可能遇到以下问题：

- **资料分散，整理成本高：** 学习内容保存在不同文件夹和平台中，难以统一管理。
- **查找知识不方便：** 复习时需要在大量文档中反复查找，也不一定记得准确的关键词。
- **知识积累与练习脱节：** 收集的资料、课堂笔记和日常错题分散保存，难以建立联系。
- **薄弱环节不清晰：** 只记录错题但缺少知识点归纳和持续跟踪，不容易判断应该优先复习什么。
- **复习安排缺乏依据：** 用户往往依靠临时记忆安排复习，容易遗漏较长时间未复习或反复出错的内容。

### 2. 系统解决方案

| 实际问题 | 系统功能 | 提供的帮助 |
|---|---|---|
| 多渠道资料分散 | 多格式文件与网页采集 | 将不同来源的学习资料集中到个人知识库 |
| 资料查找困难 | 混合检索与知识问答 | 通过自然语言问题查找相关知识，并查看关联资料来源 |
| 资料缺乏组织 | 文件夹、标签与文档管理 | 按主题和用途组织、筛选学习资料 |
| 错题难以持续跟踪 | 错题管理与复习状态记录 | 保存错误原因、关联知识点并记录复习情况 |
| 难以发现薄弱知识点 | 知识点统计与学习分析 | 汇总错题和学习记录，辅助识别需要关注的知识点 |
| 不清楚复习优先级 | 个性化智能复习建议 | 综合复习状态、薄弱知识点和最近复习时间提供复习参考 |

### 3. 典型使用流程

1. **收集资料：** 上传课程讲义、PDF、Word、代码文件，或导入网页内容。
2. **整理知识：** 使用文件夹和标签对资料分类，形成个人知识库。
3. **检索与问答：** 在学习或考前复习时输入问题，查找相关内容并结合资料来源核对回答。
4. **记录错题：** 将练习中遇到的问题、正确答案、错误原因和关联知识点录入系统。
5. **分析学习情况：** 查看错题分布、知识点统计和学习趋势，了解需要进一步巩固的内容。
6. **安排复习：** 参考系统生成的复习建议，选择相应错题进行复习，并更新复习状态。

通过这一流程，系统将分散的资料管理、知识检索、错题记录和复习安排连接起来，形成从知识积累到学习反馈的辅助学习闭环。

### 4. 项目应用价值与验证边界

本项目的实际价值在于减少学习资料整理和查找过程中的重复操作，并将个人知识资料与错题、知识点分析及复习建议结合起来，为日常学习和考前复习提供统一的辅助工具。
